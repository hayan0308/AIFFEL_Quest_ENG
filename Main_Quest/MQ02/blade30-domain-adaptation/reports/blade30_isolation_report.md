# blade30 타일 전/후 격리 비교 — 비타일 원본 baseline 확보

> 이예령·김민욱이 "타일 안 한 blade30 원본이 없어 타일화 순효과를 격리 못 했다"고 남긴 한계를 메우기 위해,
> **타일 안 한 blade30 원본 109장**에 최종 앙상블(`ensemble/`)을 그대로 돌린 결과다.
> 재학습 없음. 이예령의 타일 결과와 **같은 앙상블·같은 스크립트(ensemble_eval.py)·같은 잣대(conf≥0.05)** 라 상대 비교가 유효하다.

## 결론 (한계가 메워짐)

1. **낮은 점수의 원인은 타일화가 아니라 데이터(도메인)다.**
   blade30은 **원본 상태에서도 mAP50 0.016**으로 이미 WTBD(0.062)보다 낮다.
   → "타일화 탓인가, 데이터가 원래 어려운 탓인가?" 질문의 답: **데이터(도메인) 탓.**

2. **타일화는 해악이 아니라 소폭 플러스였다.**
   mAP50 0.016(원본) → 0.021(타일)로 오히려 약간 올랐다. damage recall은 거의 동일(0.418 → 0.405).
   → 이예령의 타일화는 나쁘지 않았고, 다만 **도메인 갭이라는 벽을 넘기엔 역부족**이었다.

3. **앙상블 우위는 원본에서도 견고.**
   단일 챔피언 damage recall 0.176 → 앙상블 0.418 (2.4배). 타일 데이터에서와 동일한 패턴.

4. **dirt는 원본에서도 사실상 실패**(AP 0.013 ≈ 0).
   원본 분포 dirt 100 : damage 91 (dirt 우세). 학습 데이터는 dirt 희귀(1:15)로 정반대 → dirt 일반화 실패는 예견된 결과.

## 정직하게 남기는 caveat

- **소스 동일성**: `blade30_yolo_defects`(원본 109장)가 이예령 `blade30_tiles`의 타일화 이전 소스인지 최종 확인 필요.
  이예령 타일 파일명(`..._r4_c2`)에 원본 stem(`Blade_10__0_...`)이 들어있으면 동일 소스 확정.
- **평가셋 불일치**: 본 측정은 원본 109장(GT dirt 100/damage 91), 이예령은 val 75타일. 분모가 달라 "정밀 동일"이 아닌
  **"같은 소스·같은 모델·같은 잣대의 참고 비교"** 수준. 격리 목적엔 충분하나 절대값 직접 뺄셈은 지양.
- **지표 정의**: ensemble_eval.py 자체 계산(conf≥0.05)이라 ultralytics 공식 val 절대값과 다를 수 있음. 단일·앙상블에 같은 잣대 → 상대 비교 유효.

## 재현 방법

```bash
# ensemble/input/images, labels 를 blade30 원본에 연결
ln -sfn <blade30_yolo_defects>/images ensemble/input/images
ln -sfn <blade30_yolo_defects>/labels ensemble/input/labels
cd ensemble && python ensemble_eval.py   # 결과: output/results.txt, summary.json
```
